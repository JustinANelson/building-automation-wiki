## Choosing a Probe

This section is an overview drawn from the part-number descriptions above and the other pages in this wiki.

The HMT330 family shares one transmitter body, and the model number selects the probe for the process:

| Model | Process |
| :--- | :--- |
| HMT331 | Cleanrooms and server rooms; short flexible probe, optional WLAN |
| HMT333 | Ducts and tight spaces |
| HMT334 | High pressure or vacuum |
| HMT335 | High temperature |
| HMT337 | High humidity or condensing conditions (warmed probe) |
| HMT338 | Pressurised pipelines |

**Applying it.** Use it where the HVAC-grade transmitters do not meet the need: cleanrooms, pharmaceutical and laboratory spaces, drying processes and harsh environments. Where cleaning agents or hydrogen peroxide are used, the chemical purge option protects the sensor; see [Humidity sensors](../concept/humidity-sensors.html). The family can output derived values such as dew point, which suit condensation protection and process control.

**Ordering.** The page note says a full orderable code comes from Vaisala's order form, which was not obtained, so these are series names and not complete codes. See [Vaisala industrial transmitters](../product-line/vaisala-industrial-transmitters.html) for the line, and [HMDW110](hmdw110.html) for a lower-cost building option.
