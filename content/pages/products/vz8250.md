## Applying the VZ8250

This section is an overview drawn from the part-number descriptions above and the other pages in this wiki.

The VZ8250 controls VAV zones, either **pressure dependent** (damper position follows the temperature demand, with no airflow measurement) or **pressure independent** (damper position is driven by an airflow loop). Pressure-independent control needs a flow signal; see [VAV control](../concept/vav-control.html) and [Airflow measurement](../concept/airflow-measurement.html). The controller also senses and controls humidity.

**Variants.** `U5000B` has no PIR; `U5500B` adds a PIR motion sensor; `U5500BP` adds the PIR and on-board Zigbee Pro. All use BACnet MS/TP.

**Checks.** Set the application mode first (pressure dependent or independent), then the airflow limits and reheat arrangement. Confirm the damper actuator arrangement, signal type and run time against the controller documentation; see [Control signals](../concept/control-signals.html). On a shared trunk with a supervisory controller, follow [BACnet MS/TP](../protocol/bacnet-mstp.html). For the matching 7000-series controller see [VT7200](vt7200.html).
