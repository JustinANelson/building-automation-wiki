## Choosing a Variant

This section is an overview drawn from the part-number descriptions above and the other pages in this wiki.

Read the part number in three parts:

| Part | Meaning (from the descriptions above) |
| :--- | :--- |
| `C` or `F` after VT7200 | `C`: floating or on/off outputs. `F`: 0-10 V analog output |
| `5031` or `5531` | `5031`: no PIR. `5531`: PIR occupancy sensor, two on/off or floating outputs |
| Final letter | None: stand-alone, network ready. `B`: BACnet. `E`: Echelon (LON). `P`: Zigbee Pro. `W`: Zigbee, for replacement on existing projects only |

**Choosing the output.** Use floating or on/off where the zone damper or valve actuator takes those signals, and the 0-10 V version for a modulating actuator; see [Control signals](../concept/control-signals.html). Choose a PIR model if occupancy should drive setback. The `W` model is not compatible with the current wireless system, so do not specify it for new work.

**Network.** The BACnet versions sit on an MS/TP trunk; see [BACnet MS/TP](../protocol/bacnet-mstp.html). The Echelon version is a LonWorks device, covered on [LonWorks](../protocol/lonworks.html), and needs a network management tool to bind it. The stand-alone versions work without a network.

**Use.** The VT7200 is a zone controller for zoning, VAV and heat/cool terminal units; see [VAV control](../concept/vav-control.html). The touchscreen equivalent is the [VZ8250](vz8250.html), and the series is described on [Viconics room controllers](../product-line/viconics-room-controllers.html).
